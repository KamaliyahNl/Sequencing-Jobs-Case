# Sequencing-Jobs-Case
Excel for implementation of job sequencing rules (FCFS, SPT, EDD, LPT) with a dynamic decision to evaluate and select the optimal schedule based on minimum mean flow time, tardiness, and makespan.

# Problems 
The following jobs are waiting to be processed at the same machine center. Jobs are logged as they arrive. In what sequence would the jobs be ranked according to the follow-
ing decision rules: (a) FCFS, (b) EDD, (c) SPT, and (d) LPT? All 
dates are specified as manufacturing planning calendar days. Assume 
that all jobs arrive on day 275. Which decision is best and why?
